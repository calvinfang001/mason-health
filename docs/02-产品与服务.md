# 产品与服务

马森营养提供五套解决方案，分别对应营养师个人、机构客户、开发者、中医食养场景与量表评估场景。

## 一、营养师智能工作台

**适用对象**：注册营养师、公共营养师、健康管理师、营养门诊

**解决什么**：单份方案从 90 分钟到 5 分钟。

**核心能力**

| 能力 | 说明 |
|---|---|
| 客户画像采集 | 基本信息、生活方式、既往史、饮食偏好结构化录入 |
| 营养素缺口分析 | 依据膳食摄入与参考摄入量（DRIs）自动计算缺口与超标项 |
| 膳食结构建议 | 按能量目标与营养素配比生成食物类别与份量区间 |
| 食材 / 菜肴替换 | 基于成分库的同营养等价替换，兼顾口味与可得性 |
| 循证依据标注 | 每条建议关联数据来源或文献，可逐条展开查看 |
| 报告输出 | 在线报告，可生成分享链接，支持 PDF 导出 |

**不做什么**：不做疾病诊断、不开具处方、不替代医师与临床营养师的诊疗决策。

---

## 二、企业健康管理

**适用对象**：体检中心、健康管理公司、保险公司、大型企业 HR / 工会

**核心能力**

- 团体健康档案集中管理，支持批量导入与分组建档
- 人群营养风险分层（按体检指标与膳食调查结果）
- 批量方案生成与统一模板管理
- 健康宣教内容库与员工自助查询
- 团体数据看板：风险分布、干预覆盖率、复评对比

**价值**：把「一次体检报告」变成「可持续的健康管理」，把个人服务能力放大为机构服务能力。

---

## 三、数据 API 与授权

**适用对象**：医疗机构、科研团队、健康类 App / 小程序开发者

**能力范围**

| 接口类型 | 内容 |
|---|---|
| 食物成分查询 | 食材、菜肴、营养素补充剂的成分与含量 |
| 营养素参考值 | DRIs 相关参考值查询与折算 |
| 药品说明书 | 化学药、中成药、生物制品说明书结构化字段 |
| 医保目录 | 药品与诊疗项目医保类型、限定支付范围 |
| 知识图谱推理 | 症状 / 病名 → 中药材 → 方剂 → 药食同源食材 |
| 批量检索 | 支持按字段组合的高级检索与分页导出 |

**授权方式**：按调用量或按年度授权，具体条款通过官网联系取得。数据授权不包含原始数据集的转售与再分发。

## 四、中医药食养

**适用对象**：中医馆、治未病中心、养生机构、药膳与食品企业

**底座**：761.08 万条关联边的中医药知识图谱。

**能回答的问题**

- 客户主诉「怕冷、手脚凉、容易腹泻」，对应的证候倾向与食养方向是什么
- 某味药材与哪些方剂、证候、疾病存在显著关联
- 药食同源目录内的食材，在特定体质下如何取舍
- 四季与地域（含高原地区）食养建议的差异

**原则**：以典籍与药典记载为依据，按关联显著性排序呈现，**不做疗效承诺**，明确区分「食养调理」与「疾病治疗」。

## 五、FFQ 问卷 SaaS

**适用对象**：科研团队、营养流行病学调查、企业健康项目、学校与社区卫生服务

**核心能力**

| 能力 | 说明 |
|---|---|
| 三档问卷深度 | 基础版（约 20 题）/ 标准版（约 30 题）/ 深度版（约 40–50 题） |
| 本土化食物清单 | 以中国居民实际膳食结构为基础，含高原地区常见食物 |
| 自动营养素折算 | 提交即完成能量与营养素计算，无需人工录入 |
| 膳食模式识别 | 输出膳食结构特征与主要风险项 |
| 个体化报告 | 面向受试者的可读报告 + 面向研究者的结构化数据导出 |

在线体验：<https://www.masonhealth.cn/data/ffq>
