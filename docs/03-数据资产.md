# 数据资产

数据是这套系统真正的底座。本页记录平台当前上线数据的规模、结构与更新机制。

> 数据口径截至 **2026 年 11 月**，与官网 <https://www.masonhealth.cn/data> 保持一致。

## 一、总体规模

| 维度 | 规模 |
|---|---|
| 启用数据集 | 52 个 |
| 专业字段 | 769 个 |
| 结构化记录 | 约 887.9 万条 |
| 数据集合（collection） | 167 个 |
| 主要存储 | MongoDB（文档型），关系与配置存 MySQL |
| 中医药知识图谱关联边 | 761.08 万条 |

## 二、四大专业板块

### 🌾 营养数据（25 个数据集 · 94,675 条）
食材与菜肴成分、营养素补充剂、保健食品、膳食参考摄入量等。
用途：膳食调查、营养素缺口计算、食材等价替换。

### 💊 药品与医保（4 个数据集 · 171,892 条）
化学药、中成药、生物制品说明书结构化字段，国家医保药品目录与限定支付范围。
用途：膳食—药物相互作用提示、特殊人群用药期间营养注意事项。

### 🏛 市场监管食品（4 个数据集 · 45,033 条）
婴幼儿配方乳粉产品配方注册、保健食品备案与注册信息。
用途：产品合规核查、特殊人群食品选择。

### 🌿 中医中药（16 个数据集 · 74,507 条）
中医典籍条文、中药材、方剂、穴位、药食同源目录。
用途：中医食养方案、药膳配伍参考、体质调理建议。

## 三、字段规范

每个数据集字段都标注三件事：

1. **字段定义** —— 这个字段到底表示什么，避免同名异义
2. **单位与取值范围** —— 例如营养素统一到「每 100 g 可食部」
3. **来源** —— 来自哪本工具书、哪份官方公告或哪篇文献

字段类型分为：主键、文本、数值、枚举、关联键、派生列（由其他字段计算得出，不落库）。

## 四、数据来源

以官方与权威机构为主：

| 来源类型 | 示例 |
|---|---|
| 国际数据库 | USDA FoodData Central |
| 国家标准工具书 | 中国食物成分表 |
| 监管机构 | 国家药品监督管理局、国家市场监督管理总局 |
| 药典与典籍 | 中国药典、中医经典著作 |
| 学术机构 | 北京中医药大学等 |

## 五、更新机制

| 数据类型 | 更新方式 |
|---|---|
| 监管类数据（药品、医保、备案） | 跟随官方公告增量更新，人工复核字段映射 |
| 食物成分数据 | 版本化更新，保留历史版本以支持回顾性研究 |
| 文献证据 | 按证据等级分层，新增文献需经科学顾问审核后入规则库 |
| 知识图谱 | 关联边增量构建，新增关系需通过显著性检验 |

**版本可追溯**：每次数据更新保留时间戳，历史报告可回溯到生成当时的数据版本。

## 六、检索能力

- **关键词检索**：多字段并行匹配，中文口语化表达可识别
- **高级检索**：字段级组合条件（等于、包含、区间）
- **图谱检索**：症状 / 病名 / 药材的多跳关联查询，按显著性排序
- **性能**：单次关键词检索在十万级数据集上为**毫秒级**

## 七、数据使用与边界

- 平台展示的数据仅供专业参考，**不构成诊断或用药建议**
- 原始数据集不对外转售，API 授权仅限约定用途
- 尊重来源方版权，转载与引用请注明原始出处
