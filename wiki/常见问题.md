# 常见问题

## 面向营养师

**Q1：生成一份方案真的只要 5 分钟？**
A：指的是「从输入客户信息到拿到可转发报告」的时间。前提是客户基本信息与膳食调查已完成录入。相比之下，传统流程（翻工具书核对成分、手工计算、逐条抄文献、排版）通常需要 60–90 分钟。

**Q2：报告里的结论我能直接给客户吗？**
A：可以，但需要你作为营养师做最后判断。系统给的是候选方案与证据依据，个体化调整仍是你的专业职责。

**Q3：如果数据里没有我客户吃的地方特色食物怎么办？**
A：可以通过「食材等价替换」选择营养成分接近的条目，也可以在反馈入口提交缺失食物，我们会按优先级补充。高原地区常见食物已在重点补充清单内。

**Q4：注册营养师和公共营养师都能用吗？**
A：都能用。功能上没有资质门槛差异，但涉及疾病相关的营养干预建议，应由具备相应执业范围的营养师判断。

## 面向机构

**Q5：能对接我们现有的体检系统吗？**
A：可以通过数据 API 对接。常见方式是：体检系统推送结构化指标 → 平台生成营养风险分层与建议 → 回写报告或推送到员工端。

**Q6：团体报告会不会千人一面？**
A：不会。方案基于个体输入生成，但团体项目可统一模板与话术风格，保证品牌一致性。

**Q7：数据存放在哪里？安全吗？**
A：数据存放于国内云服务器，访问经 HTTPS 加密；个人健康信息仅用于生成其本人报告，不对外提供、不用于模型训练。

## 面向开发者

**Q8：有 API 文档吗？**
A：有，属于「数据 API 与授权」服务范围。请通过官网联系获取接口清单与鉴权说明。

**Q9：能做图谱的嵌入式展示吗？**
A：可以，支持以 iframe 或 API 方式接入知识图谱检索能力。

**Q10：授权后可以缓存数据吗？**
A：允许在约定范围内的临时缓存以提升性能，但不允许落库长期留存与再分发。具体以授权协议为准。

## 通用

**Q11：这些数据是免费的吗？**
A：官网的数据查询与服务自 2.0 起对个人用户免费开放。机构级 API 授权、定制化部署与团体服务按协议收费。

**Q12：为什么不提供疾病治疗方案？**
A：合规要求，也是专业边界。营养干预与疾病治疗是两件事，前者我们能做，后者必须由医疗机构完成。

**Q13：发现数据有误怎么办？**
A：通过官网「联系我们」提交勘误，注明数据集、字段与依据来源，我们会在复核后更新并保留修改记录。
