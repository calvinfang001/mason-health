# 中医药知识图谱

## 为什么做图谱

传统的关键词检索只能回答「有没有这个词」，回答不了「这两件事是什么关系、关系有多强」。

营养师实际会问的是：

- 「客户说怕冷、手脚冰凉，这算什么倾向？食养上往哪个方向走？」
- 「枸杞这味药，和哪些证候、方剂、疾病有实证关联？」
- 「血压偏高的人，哪些药食同源食材是常用搭配，哪些要避开？」

这类问题的本质是**关系查询**，需要图谱而不是索引。

## 规模

| 指标 | 数值 |
|---|---|
| 关联边（edge） | **761.08 万条** |
| 节点类型 | 中药材、方剂、证候、症状、疾病、穴位、食材、典籍条文 |
| 关联属性 | 关联类型、来源文献、显著性（p 值）、证据强度 |

## 结构

```
症状 / 病名 ──┬── 证候 ──┬── 方剂 ── 中药材
             │          └── 穴位
             └── 中药材 ── 药食同源食材
```

每条边都带 `来源` 与 `显著性`，前台按 p 值升序呈现——**先说证据最强的，不按热度排序**。

## 检索策略

疾病与症状的匹配分四级，逐级兜底：

1. **整串命中** —— 输入「高尿酸血症」直接命中标准病名表（含 150 条中文病名 → 英文关键词映射）
2. **原话包含** —— 输入「我有脂肪肝怎么办」提取出「脂肪肝」（长词优先）
3. **直接输英文** —— 支持英文病名与药材名
4. **口语兜底** —— 仅在前三级全部落空时启用：剥掉口语词（「有点」「比较」「的症状」）后做前缀优先匹配

第 4 步的「前缀优先」是刻意设计的：输入「血压」应命中「血压高」，**不能带入语义相反的「低血压」**；只有当没有任何前缀匹配时，才退化为包含匹配（例如「结石」→ 肾结石 + 胆结石）。

## 边界声明

- 图谱呈现的是**典籍与文献中记载的关联**，不等同于临床疗效结论
- 所有输出定位为**食养调理参考**，不构成诊断、处方或治疗建议
- 涉及疾病诊疗、妊娠、儿童、肝肾功能异常等情形，须由执业医师或临床营养师判断

## 常见问题

**Q：图谱和《中国药典》是什么关系？**
A：药典是图谱的重要来源之一。图谱把药典条文、方剂组成、证候描述等结构化后建立关联，但不会超出原文记载做推断。

**Q：为什么同一个症状搜出来的结果和别家不一样？**
A：排序依据不同。我们按证据显著性（p 值）排序，而不是按搜索热度或商业合作排序。

**Q：可以调用图谱 API 吗？**
