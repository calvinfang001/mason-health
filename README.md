# 马森营养 Mason Health

> 营养师的智能工作台 —— 用数据与循证，让中国营养师的专业价值被看见。

## 我们在解决什么问题

全国备案在册的注册营养师约 **2 万人**，而营养健康服务的人才缺口已突破 **400 万**。与此同时，营养师约 **70%** 的工作时间耗在翻数据库、做表格、写重复文案这类事务性劳动上。

马森营养做的事情，是把这 70% 交给系统，把判断权留给营养师。

| 传统流程 | 使用马森营养 |
|---|---|
| 翻 3–5 本工具书核对成分数据 | 结构化数据一次检索命中 |
| 手工计算营养素、能量与配比 | 自动计算并标注依据来源 |
| 逐条抄写文献结论 | 循证规则库检索，结论可溯源 |
| 单份方案 90 分钟 | 单份方案 **5 分钟** |
| 输出为不可复用的 Word | 可转发、可追踪的在线报告 |

## 产品与服务

### 1. 营养师智能工作台
输入客户基本信息与健康诉求，输出可转发的个性化营养方案：膳食结构建议、营养素缺口分析、食材与菜肴替换方案、生活方式干预要点，每条结论均可追溯到数据或文献。

### 2. 企业健康管理
面向体检中心、健康管理公司、保险公司与大型企业，提供团体健康档案、人群营养风险分层、批量方案生成与健康宣教内容。

### 3. 数据 API 与授权
将营养数据库与知识图谱以 API 形式对外授权，供医疗机构、科研团队与健康类应用接入。

### 4. 中医药食养
以 761 万条关联边构建的中医药知识图谱为底座，支持「症状 / 病名 → 中药材 → 方剂 → 药食同源食材」的多跳推理，覆盖体质辨识与四季食养。

### 5. FFQ 问卷 SaaS
半定量食物频率问卷（FFQ）的在线化与本土化：支持三档问卷深度、自动营养素折算、膳食模式识别与个体化报告导出。

## 中医药知识图谱

区别于关键词检索，图谱做的是「关系」：某味药材与哪些证候、方剂、疾病、穴位、食材存在关联，关联强度如何。

- 规模：**761.08 万条关联边**
- 能力：白话主诉理解（「血压高」→ 眩晕 / 肝阳上亢）、口语同义词归一、疾病四级匹配策略
- 原则：**证据优先**，按显著性（p 值）排序呈现，不做疗效承诺

在线体验：<https://www.masonhealth.cn/kg>

## 合规边界

我们坚持三条底线：

1. **数字优先，不做口头营养** —— 所有结论必须能被追溯到数据来源或文献。
2. **合规边界清晰** —— 平台输出为生活方式干预建议，**不构成医疗诊断，不替代药物治疗**；涉及疾病诊疗的内容一律引导至执业医师。
3. **营养师主导** —— AI 负责效率，营养师负责判断，客户关系的主体永远是人。
